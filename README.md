# driverbit-chart-for-altoids
Having the right driver bit when you need it is a problem. There are widely available 3d prints of driver bit organizers to fit inside the durable, compact Altoids tin. The problem is that bit sizes are hard to distinguish, especially when choosing between adjacent sizes.

This project is a simple website that can make a label for the Altoids tin. Users can input any bits into any slot.
